# VRAVIO — описание проекта

VRAVIO объединяет четыре редактора в одном окне: растровую графику, векторную графику, звук и видео. Сверху расположена компактная полоса рабочих сред; внутри каждой среды остаются собственные вкладки документов и инструменты. Открытые среды сохраняют состояние при переключении. Веб-версия опубликована на GitHub Pages; настольная версия использует Tauri и тот же собранный интерфейс.

Проект основан на открытых исходниках PhotoCraft, VectorCraft, SoundCraft и FilmCraft. Они подключены как Git-подмодули и закреплены на конкретных коммитах. VRAVIO добавляет оболочку, оформление, интеграционные мосты и локальные патчи при сборке. Исходные репозитории не переписываются. Тексты лицензий и уведомления сторонних компонентов включаются в веб-сборку в `third-party-notices/`.

## Что интегрировано

- Растровая и векторная среды обмениваются изображениями через общий буфер. Встроенное изображение в векторном документе можно открыть через контекстное меню или свойства в растре, изменить и вернуть на исходное место сохранением.
- Несохранённые растровые документы имеют локальные послойные снимки для восстановления после перезагрузки страницы. Перед закрытием документа или среды с несохранёнными изменениями показывается подтверждение.
- В растре есть фильтр реставрации старых фотографий Vetor Restore. Модели загружаются по необходимости и работают в браузере; результат можно открыть новым документом с исходным и обработанным слоями либо добавить в текущий документ.
- Внешнее веб-приложение может передать PNG в VRAVIO через `postMessage` и получить результат после сохранения. Пример связан с редактором-сортировщиком проекта реставрации. Это браузерный обмен, не системный обработчик `vravio://`.
- Темы и языки синхронизируются между средами, у которых есть соответствующие настройки. Внутренний интерфейс звукового редактора пока остаётся англоязычным.

## Ограничения

Редакторы сохраняют свои форматы и собственные модели документов; общего редактируемого формата для всех четырёх сред нет. Обмен между растром и вектором передаёт отрисованное изображение, а не историю или структуру слоёв. Восстановление после перезагрузки реализовано для растровых документов. Настольная сборка для macOS создаётся в CI, но её поведение на конкретном Mac нужно проверить отдельно. Публикация в GitHub Pages не делает сайт полностью автономным: при первой реставрации требуется загрузка весов моделей.

## Структура

- `src/` — оболочка и межредакторные сообщения.
- `upstream/` — закреплённые исходники четырёх редакторов.
- `brand-editors.ps1`, `build-editor.ps1`, `build-web.ps1` — патчи интерфейса и сборка.
- `restorer/`, `models/restore/` — диалог и модели реставрации.
- `src-tauri/` — настольная оболочка Windows/macOS.
- `.github/workflows/web.yml` — сборка редакторов, сайта и настольных пакетов.

См. [README.md](README.md) для технических подробностей, [PUBLISH_GITHUB_RU.md](PUBLISH_GITHUB_RU.md) для публикации и [MACOS_RU.md](MACOS_RU.md) для Mac.
