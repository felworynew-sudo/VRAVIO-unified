# Как публиковать VRAVIO на GitHub

Основной репозиторий: `https://github.com/felworynew-sudo/VRAVIO-unified`. Сайт: `https://felworynew-sudo.github.io/VRAVIO-unified/`. Ветка публикации — `main`.

## Если проект скачан на другой компьютер

Установите Git и клонируйте репозиторий вместе с исходниками редакторов:

```sh
git clone --recurse-submodules https://github.com/felworynew-sudo/VRAVIO-unified.git
cd VRAVIO-unified
```

Если папка проекта уже перенесена и её `.git` сохранена, проверьте состояние и подмодули:

```sh
git status --short
git submodule update --init --recursive
```

Если передана только папка без `.git`, сначала клонируйте репозиторий, а свои изменённые файлы перенесите в новый клон. Не выполняйте `git init` поверх копии с подмодулями: их связи с основным репозиторием нужно сохранить.

## Публикация изменений

Работайте в ветке, проверьте изменённые файлы и создайте коммит:

```sh
git switch main
git pull --ff-only --recurse-submodules
git status --short
git add <нужные-файлы>
git commit -m "Описание изменения"
git push origin main
```

Не добавляйте в коммит `dist/`, `target/`, `node_modules/`, локальные фотографии или веса, отсутствующие в проекте. Папки `upstream/*` являются подмодулями: при обновлении редактора основной коммит записывает **ссылку на его коммит**, а не копию всех файлов. `brand-editors.ps1` меняет рабочие копии при сборке; его результат внутри подмодулей коммитить не нужно.

Push в `main` запускает [Build web](https://github.com/felworynew-sudo/VRAVIO-unified/actions/workflows/web.yml). Дождитесь успешного завершения задач четырёх редакторов, сайта, публикации Pages и настольных пакетов. Затем откройте сайт с обновлением страницы. В разделе **Artifacts** завершённого запуска лежат веб-сборка, установщик Windows и универсальный пакет macOS DMG. Если сборка упала, сайт может остаться на прежнем коммите; смотрите журнал упавшей задачи, а не делайте повторный push вслепую.

В настройках репозитория **Settings → Pages** источником должен быть **GitHub Actions**. Для другого GitHub-аккаунта потребуется изменить адреса сайта/репозитория и проверить базовый путь Vite; до этого опубликованный код использует путь `/VRAVIO-unified/`.
